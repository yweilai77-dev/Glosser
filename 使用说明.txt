划词查询工具 · 使用说明
================================

一、这是什么
  常驻系统托盘的小工具。在任何软件里（浏览器、Word、PDF 阅读器、聊天窗口等）
  选中一段文字，连按两次 Ctrl+C，鼠标旁边就会弹出气泡解释这个词。

  查词顺序：先查本地词典（秒回、免费），查不到再调 AI 接口解释。

二、使用方法
  1. 双击 划词查询.exe 启动（首次运行会自动弹出设置窗）
  2. 在任意软件里选中文字
  3. 按查询热键（默认 Ctrl+Alt+Q，可在设置里修改）
  4. 气泡出现在鼠标旁，点击气泡或等待数秒自动消失

  若某些窗口不支持自动复制（气泡会提示"未检测到划词复制"），
  先手动 Ctrl+C 复制，再按查询热键即可查询剪贴板内容。

  查询热键可在 设置 → 常规 → 查询热键 → 修改 里自定义，
  程序会自动检测所选组合键是否被占用。

三、设置说明
  右键托盘图标 → 设置，分三个页签：

  【AI 查询】
    - 启用 AI 查询：本地词典查不到时才走 AI
    - 接口地址：OpenAI 兼容的 Chat Completions 接口
      （默认 https://api.openai.com/v1/chat/completions，也可填任何
       兼容中转站、本地部署地址，自动补全路径）
    - API Key：填你服务端的密钥，点"显示"可明文查看
    - 模型名称：填服务端支持的模型
    - 超时：AI 响应超时秒数
    - 查询缓存：查过的词条在有效期内直接复用（来源栏显示 CACHE），
      不消耗 Token。有效期默认 24 小时，可在本页调整。
      缓存保存在 exe 同目录 cache.json。

  查询顺序：本地词典 → 缓存 → AI。

  【本地词典】
    表格里直接维护词条和解释。添加/删除后点保存。
    命中本地词典的词条零延迟、不花 token，建议把常用术语都放这里。

  【常规】
    - 气泡自动关闭时间
    - 同词重复查询间隔：同一词在间隔内不重复查询，省 token（默认 3 秒）
    - 开机自动启动（写当前用户注册表 Run 项）
    - 查询热键：点"修改"后按下新的组合键即可自定义，自动检测占用

  【防连发】
    热键 600 毫秒内重复按会被忽略，避免手抖触发多次查询。

四、配置文件
  所有设置存在 exe 同目录的 settings.json，可备份、可手改、可复制到别的电脑。
  词典里的解释若含换行，手改 json 时用 \n 表示。

五、常见问题
  Q: 启动时提示"热键 Ctrl+C 注册失败"？
  A: 有同类工具（欧路、有道、其他划词软件）占用了 Ctrl+C，先关掉它们再启动本程序。

  Q: 弹出"查询失败[...]..."？
  A: 新版错误信息自带状态码、最终请求地址和服务端返回原文，按状态码对照排查：
     401      API Key 不对（或格式不对，检查有无多余空格）
     403      无权限 / Key 被禁用
     404      接口地址或模型名不对（看气泡里的"请求地址"是否合理）
     429      限流了，稍后再试或换模型
     5xx      服务端问题，等一下再试
     若是"无法解析/连接"类错误，是网络或代理问题，检查网络环境。

  Q: 双击打开时 Windows 提示"已保护你的电脑"？
  A: 本程序没有商业数字签名，属正常提示。点"更多信息"→"仍要运行"即可。

  Q: 连按两次 Ctrl+C 没反应？
  A: 确认托盘区有本程序图标；确认选中文本不是密码框、图片等不可选内容；
     确认两次按键间隔在设置范围内。

  Q: 提示"自动复制失败"？
  A: 某些高权限或特殊窗口会拒绝程序的自动复制。此时手动 Ctrl+C 复制，
     再按 Ctrl+Alt+Q 查询即可，功能不受影响。

六、重新编译（可选）
  修改 划词查询.cs 源码后，双击 build.bat 即可重新生成 exe。
  需要系统自带 .NET Framework 4.x（Windows 10/11 自带）。
